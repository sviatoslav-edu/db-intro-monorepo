# Частина 5
_Інтернет магазин ігор (альтернатива Steam)_

## Нормалізація
### purchase і review
Відсутня `UNIQUE CONSTRAINT` для `credential_id/profile_id`, що приводить до того що користувач може купити гру, навіть якщо її вже купив, або залишити декілька рецензій/відгуків на гру. Це не проблема нормалізації, але бізнес логіки.
### game_media, game_tag і achievement
Використання `SERIAL` для `FK` замість `INT`. Для точності краще використати `INT`
### studio_id і publisher_id
Були дискусії щодо `studio_id + publisher_id`, адже якщо студія=видатницство, то ми зберігаємо одне значення двічі. Але оскільки студія розробки не завжди є студією видатництва, тому два окремих поля є виправданими.
